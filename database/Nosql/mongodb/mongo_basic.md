## MongoDB vs SQL Analogy

- **Database** → **Database**
- **Collection** → **Table**
- **Document** → **Row**
- **Field** → **Column**
- **Index** → **Index**
- **_id** → **Primary Key**

## Key Differences

- **Schema**:
  - **MongoDB**: Schema-less (flexible)
  - **SQL**: Schema-based (fixed structure)

- **Joins**:
  - **MongoDB**: Embedded Documents or References
  - **SQL**: Joins across tables

- **Query Language**:
  - **MongoDB**: JavaScript-like query syntax
  - **SQL**: Structured Query Language (SQL)

- **Joins**:
  - **MongoDB**: `$lookup`
  - **SQL**: `JOIN`

- **Schema Validation**:
  - **MongoDB**: Optional schema validation
  - **SQL**: Enforced constraints (NOT NULL, UNIQUE)
